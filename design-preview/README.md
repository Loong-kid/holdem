# 홀덤 디자인 시안 1

운영 화면에 적용하지 않은 독립 미리보기입니다. `holdem-design-preview.html` 하나를 브라우저로 열면 서버 없이 볼 수 있습니다. 이 파일은 운영 CSS와 시안 CSS/JS를 내장한 검토용 묶음입니다. 또는 저장소 루트에서 정적 서버를 실행해 `/design-preview/`로 접속하세요.

## 방향

현재 녹색 펠트와 금색 액션을 유지합니다. 밝은 나무색 레일은 짙은 회녹색으로 바꾸고, 강한 발광 효과는 얇은 내 차례 테두리로 대체합니다. 카드와 스택은 밝게, 나머지 메뉴는 조용하게 처리합니다. 게임 화면의 중심은 테이블과 내 액션입니다.

- 바탕 `#151d1b`, 패널 `#202c27`, 펠트 `#20513f`, 액션 `#dbc18a`, 글자 `#edf0e8`, 보조 글자 `#adbcb0`.
- 한글은 기존 시스템 글꼴을 활용하고 숫자는 Bahnschrift 계열로 정렬합니다. Holdem 표기에만 로컬 Palatino 계열을 사용합니다. 외부 폰트 요청은 없습니다.
- 상단 방/블라인드/메뉴 → 가운데 테이블 → 하단 액션 순서입니다. 채팅과 로그는 보조 위치에 둡니다. 모바일에서는 보조 패널을 버튼으로 여닫습니다.
- 배경 장식, 움직이는 칩, 새로운 대시보드는 추가하지 않습니다. 기존 화면의 가독성과 재질감을 소폭 다듬는 제안입니다.

## 비교 범위

`현재 스타일`은 운영 `static/style.css`를 불러와 같은 6인 예시 핸드에 적용합니다. 비교가 가능하도록 기본 배치와 미리보기 전용 메뉴는 공통으로 구성했으므로 운영 화면의 픽셀 단위 복제는 아닙니다. `개선안`은 그 위에 시안 스타일을 적용합니다. 입장 화면도 비교할 수 있습니다.

베팅 금액·슬라이더·로컬 채팅·입장 전환은 시연 가능합니다. 실제 서버 연결, 게임 진행, D1 쓰기, 트레이너 점수 저장은 없습니다. 나머지 메뉴는 시안 안내를 표시합니다. 모든 인물과 핸드는 예시입니다.

## 파일

- `index.html`: 독립 미리보기 화면
- `preview.css`: 공통 비교 배치 + 개선 스타일
- `preview.js`: 서버 없는 예시 데이터와 조작
- `holdem-design-preview.html`: 파일 하나로 열 수 있는 검토용 묶음
- `screenshots/`: 실제 브라우저 렌더 결과

운영 HTML/CSS/JS, 게임 규칙, Workers 설정은 수정하지 않습니다. Cloudflare 배포 빌드는 이 폴더를 포함하지 않습니다.

320 / 375 / 414 / 768 / 1440px에서 두 스타일과 두 화면을 확인했습니다. 가로 넘침과 JavaScript 오류가 없고, 금액 프리셋·액션 안내·로컬 채팅·입장 전환·대화상자·키보드 포커스·동작 줄이기 및 단일 HTML 파일 열기를 검증했습니다. 게임 서버 연결은 발생하지 않았습니다.
